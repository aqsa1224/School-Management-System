# Functional Requirements

## Admin

- Login securely
- Manage student records
- Manage teacher records
- Manage classes
- Manage subjects
- Manage fee records
- View attendance
- Manage examinations
- Publish results
- Upload notices
- Generate reports
- Manage system settings

- Login securely
- View assigned classes
- Mark student attendance
- Upload homework
- Enter examination marks
- View timetable
- View student profiles

## Student

- Login securely
- View profile
- View attendance
- View timetable
- View homework
- View examination results
- View fee status
- Read notices
