7. Class Subjects

9. Exams
10. Marks
11. Fees
12. Homework
13. Notices
14. Timetables

---

## Relationships

- One Role can have many Users.
- One Class can have many Students.
- One Teacher can teach many Subjects.
- One Subject belongs to one Class.
- One Student can have many Attendance records.
- One Student can have many Exam Marks.
- One Student can have many Fee records.
